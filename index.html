03 / INSTALL A SENSOR LINK
  1. Open this dashboard in a browser with Web Serial support, such as Chrome on your Chromebook.
  2. Load the starter sketch onto your ESP32 with your board’s normal programming tool. This replaces that board’s existing sketch—back it up first.
  3. Use a USB data cable. Close the serial monitor, choose 115200, then tap Connect.
  4. Add your sensor driver to the sketch. Named sensor values appear here automatically; no dashboard edits needed.
